# PC Service Manager

Інформаційна система для автоматизації роботи сервісного центру з ремонту комп'ютерної техніки.

## Опис проєкту

PC Service Manager дозволяє вести облік клієнтів, пристроїв, ремонтних заявок та виконаних робіт, а також контролювати процес ремонту та переглядати статистику роботи сервісного центру.

## Функціональні можливості

### Авторизація та ролі

Система підтримує три рівні доступу:

- Адміністратор
- Оператор
- Майстер

### Управління клієнтами

- Додавання клієнтів
- Редагування даних
- Видалення записів
- Пошук клієнтів

### Управління технікою

- Реєстрація пристроїв
- Прив’язка пристроїв до клієнтів
- Редагування та видалення

### Управління заявками

- Створення заявок
- Призначення майстра
- Зміна статусів ремонту
- Перегляд історії ремонту

### Ремонтні роботи

- Облік виконаних робіт
- Вартість ремонтних операцій
- Прив'язка робіт до заявки

### Dashboard

- Кількість клієнтів
- Кількість пристроїв
- Кількість ремонтів
- Кількість майстрів
- Статистика заявок
- Загальна вартість виконаних робіт

### Інтерфейс

- Blue Demon Theme
- Light Demon Theme
- Пошук по таблицях
- Footer
- Інформаційний банер

## Структура бази даних

Проєкт використовує SQLite та містить таблиці:

- users
- clients
- devices
- statuses
- repair_requests
- repair_operations
